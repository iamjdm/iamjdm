## 💼 Live Projects

### **[TeaZen Boba Bar](https://github.com/iamjdm/Boba_Shop)** — Full-Stack Capstone
*Deployed live on Render*

[![Live Demo](https://img.shields.io/badge/Live_Demo-46E3B7?style=for-the-badge&logo=render&logoColor=white)](https://boba-shop-twv8.onrender.com)
[![GitHub](https://img.shields.io/badge/GitHub-%23121011.svg?style=for-the-badge&logo=github&logoColor=white)](https://github.com/iamjdm/Boba_Shop)

A complete full-stack web platform for a boba shop, built from scratch and deployed to production:
- **Backend:** Python Flask REST API with 10+ endpoints for menu, orders, events, and job applications
- **Database:** PostgreSQL with relational schema (7 tables), SQLAlchemy ORM, referential integrity. Migrated from MySQL for cloud deployment
- **Frontend:** Vanilla JavaScript with responsive design, Fetch API for async communication
- **AI Integration:** Groq-powered AI chatbot grounded on a custom knowledge base answering menu, allergen, and event questions in real time
- **Features:** Live menu browsing, shopping cart with checkout, event calendar with RSVP, job application portal

**Tech Stack:** Flask | PostgreSQL | SQLAlchemy | Vanilla JS | HTML5/CSS3 | Groq API

### **[NASA Drone Safety Flowchart System](https://github.com/iamjdm/ND-drone-flowchart)** — NASA Research Tool
*Built for NASA-funded drone safety research at Notre Dame · Live on GitHub Pages*

[![Live Demo](https://img.shields.io/badge/Live_Demo-181717?style=for-the-badge&logo=github&logoColor=white)](https://iamjdm.github.io/ND-drone-flowchart/)
[![GitHub](https://img.shields.io/badge/GitHub-%23121011.svg?style=for-the-badge&logo=github&logoColor=white)](https://github.com/iamjdm/ND-drone-flowchart)

A browser-based interactive data visualization and diagram editor used by researchers to map safety arguments for autonomous drone kill-switch systems:
- **Modes:** Goal Structuring Notation (GSN), ERD, and flowchart with 6 typed node classifications
- **Editing:** 50-step undo/redo, snap-to-grid, multiselect, real-time inspector panel
- **Export:** PNG/SVG/JSON export, shareable URL state, auto-save
- **Navigation:** Custom Canvas API minimap with live viewport tracking

> Contributions recognized for inclusion in a forthcoming **IEEE Transactions on Software Engineering** publication.

**Tech Stack:** Cytoscape.js | Canvas API | Dagre | Vanilla JS | HTML5/CSS3
