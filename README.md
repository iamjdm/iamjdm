## 💼 Featured Projects

### **[TeaZen Boba Bar](https://github.com/iamjdm/Boba_Shop)** — Full-Stack Capstone Project
*Senior seminar project demonstrating modern full-stack web development*

A complete web platform for a boba shop featuring:
- **Backend:** Python Flask REST API with 10+ endpoints for menu, orders, events, and jobs
- **Database:** MySQL with relational schema (7 tables), ORM via SQLAlchemy, referential integrity
- **Frontend:** Vanilla JavaScript with responsive design (mobile-optimized), Fetch API for async communication
- **AI Integration:** Ollama-powered chatbot assistant that answers menu/allergen/event questions using grounded knowledge base
- **Features:** Live menu browsing, shopping cart with checkout, event calendar with RSVP, job application portal, AI order summaries
- **Deployment:** Localhost with environment configuration, CORS handling, error management

**Tech Stack:** Flask | MySQL | SQLAlchemy | Vanilla JS | HTML5/CSS3 | Ollama LLM  
**Key Skills Demonstrated:** Database design, API development, AI/ML integration, full-stack debugging, responsive UI/UX

### **[NASA Drone Safety Flowchart System](https://github.com/iamjdm/ND-drone-flowchart)**
*Browser-based graph editor built for NASA-funded autonomous drone research at Notre Dame University*

A pure front-end tool used by researchers to map safety arguments and test coverage for kill-switch functionality in autonomous drone systems. Features include:
- **Graph editing:** Add/delete nodes and edges, choose from 5 shapes (rectangle, circle, diamond, hexagon), drag to reposition
- **Inspector panel:** Live label editing, per-node width/height control, and real-time text-wrap width adjustment
- **Auto-Layout:** One-click hierarchical arrangement via the Dagre algorithm for complex safety trees
- **Import/Export:** Save and load full flowcharts as JSON; pre-loaded sample demonstrates a G/S/O safety argument structure

**Tech Stack:** Cytoscape.js | Dagre | Vanilla JS | HTML5/CSS3  
**Key Skills Demonstrated:** Graph visualization, event-driven UI, DOM manipulation, async file I/O, data-driven rendering
